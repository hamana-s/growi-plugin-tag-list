# growi-plugin-tag-list

GROWI の全タグを一覧表示し、各タグをそのタグの検索結果ページ（`/_search?q=tag:タグ名`）へのリンクにするスクリプトプラグインです。

## 使い方

ページ本文に次のように書きます。

```
$taglist()                      全件を件数の多い順に表示
$taglist(sort=name)             全件を名前順に表示
$taglist(num=20)                上位20件だけ表示
$taglist(num=20, more)          20件表示し、「さらに表示」ボタンで20件ずつ追加
$taglist(filter=営業部)         「営業部:」で始まるタグだけ表示
$taglist(large, newline)        大きめの文字で、1行に1タグずつ表示
```

| 引数 | 内容 | 既定値 |
| --- | --- | --- |
| `sort` | `count`（件数の多い順）または `name`（名前順） | `count` |
| `num` | 表示する件数。`more` と併用したときは、ボタン1回で追加する件数も兼ねる | 全件 |
| `more` | 書くと「さらに表示」ボタンを出す。`num` がないときは無視する | なし |
| `filter` | 指定した部門のタグだけ表示する。タグ名は `部門名:案件名` の形にしておく（全角の `：` も可）。一覧では部門名を外して案件名だけを表示する | 全部門 |
| `large` | 書くとタグを大きめ（175%）に表示する | なし |
| `newline` | 書くとタグを1行に1つずつ表示する | なし |

## インストール

GROWI の管理画面 → プラグイン で、このリポジトリの URL を入力してインストールし、有効化します。

## 注意

タグは `/_api/tags.list` から取得します。このAPIはページの閲覧権限で絞り込まないため、閲覧者が見られないページに付いたタグも一覧に表示されます。

## ビルド

```
npm install
npm run build
```

GROWI はリポジトリを直接取得するため、`dist/` もコミットしてください。
